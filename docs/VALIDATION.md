## 复现

```sh
python -B -m unittest discover -s tests -v
node tests/test_frontend.mjs
python skills/vehicle-sales-opportunity/scripts/build_dashboard.py --input skills/vehicle-sales-opportunity/assets/demo.json --output out/check
```

输出目录必须是新目录。运行仅写本地，不上传数据、不访问账号。Node仅用于开发验证，核心生成器无需Node。
