# 汽车、摩托车、UTV、ATV与船舶

共用流程是“定义对象与指标 → 核验数据 → 可比分析 → 呈现 → 机会假设 → 验证”。通用不意味着所有行业可以共用统计口径或参数。

| 对象 | 型号拆分与适配维度 | 易混问题 | 可验证的研究方向 |
|---|---|---|---|
| 汽车 | 车系、代际、年款、车身/动力/配置 | 系列合计当子车型；CY与MY；销量当VIO | 场景、代际接口、细分用途、竞品与渠道 |
| 摩托车 | 型号、平台、排量、道路/越野/旅行、年款 | 发动机销量当整车；越野与上牌范围不同 | 骑行场景、装载、人机、保护件和安装空间 |
| UTV / SxS / ROV | 平台、座位、年款、动力、版本、滚笼/货箱/底盘 | UTV与ATV混合；2座/4座/CREW合计强拆；召回数当销量 | 作业/运动场景、载物、遮挡、维护、具体接口 |
| ATV | 工具/运动、成人/青少年、单人/双人、排量、年款 | 青少年与成人合计；参与品牌样本当全国 | 使用人群、货架与牵引约束、防护和维修 |
| 船舶 | 船体型号、长度、用途、年款、舷内/舷外动力、配置 | 艘数/发动机台数/拖车量；登记与在用；淡水/海水用途 | 收纳、停泊、维护、腐蚀环境、具体船体适配 |

## 数字与时间

- 零售销量、批发出货、交付、新注册是不同流量；保有量/VIO是存量；召回批次是特定范围的历史数量。
- 只在同国家、同载具类型、同指标和一致系列边界中比较。日历同比需同月份；强季节性不消失，单月同比仍不能代表全年趋势。
- 船舶用艘，其他用台（可按交付要求改为辆）；发动机、附件和整机不能混计。
- 不同类型可以放同一个工作台，但不得做一个混合“车辆总市场”KPI。
- 只有年/季度数则保持其粒度。不能为迁就月度生成器平分，也不能把年度召回批次数换成月销。

## 年款和版本

原始资料只能归属到某年款区间/配置合并组时，保留区间和统计组。目录能列出版本，不代表数量能分配到版本。目录的型号/年款/版本层与数量的可归属层分开建模，用稳定ID和关系表连接；无法分摊的父组数只显示一次。

## 迁移参数与商业结论

不能把汽车存活曲线、UTV情景折减率或某船型适配结论迁移到其他行业。缺乏实证参数时可以设计敏感性情景，必须标为假设；其区间不是统计置信区间，不是严格上下界。销量信号仅决定先研究什么，不能代替需求、适配、渠道和经济验证。
